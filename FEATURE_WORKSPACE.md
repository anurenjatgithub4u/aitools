# FindurAI Workspace

Version: 1.0

Status: MVP

---

# Vision

FindurAI Workspace is an AI-native knowledge workspace designed specifically for people who use AI tools every day.

Unlike Obsidian, which stores personal notes, FindurAI stores reusable AI knowledge.

Users should be able to organize, connect, search, generate and reuse everything they create with AI.

This includes:

- Prompts
- Workflows
- Research
- AI Outputs
- Code Snippets
- Decisions
- References
- Notes

The product should feel like a combination of:

- Obsidian
- Notion
- Cursor
- GitHub

built specifically for AI users.

---

# Main Objective

Users should never lose valuable AI knowledge.

Everything should become reusable.

Everything should connect together.
